# mazemaze

日本語の記事を読みながら、一部を英語に置き換えて、英語を読むことに慣れるための、**自分専用の iPhone アプリ**です（`ios/`、SwiftUI + WKWebView）。

- アプリの中のブラウザで、許可したサイト（Yahoo!ニュースなど）を普通に読むと、本文の日本語の一部が英語に置き換わります。
- 英語に置き換えた部分以外の日本語は、一文字も変わりません。変換に失敗した箇所は日本語のまま残ります。
- 英語部分をタップすると、元の日本語が出ます。単語をタップすると、標準辞書と、この文での意味（AI）を調べられます。
- **翻訳・辞書・意味は、すべて iPhone の中だけで動きます。** Mac もサーバーもクラウドも使いません。文章は、iPhone の外に出ません。通信は、読んでいるサイトそのものを開くとき、Apple 翻訳の言語データをダウンロードするとき、そして、アドレス欄に入れた検索語を、設定で選んだ検索サービスに送るときだけです。
- App Store には出しません。Xcode から、自分の iPhone にだけ入れます。

> **Mac のローカルモデル版について**: Mac で Ollama（Qwen3.5 9B）を動かして翻訳する版（FastAPI サーバー、Web UI、QR ペアリング、Tailscale での外出先利用を含む）は、ブランチ **`mac-local-model`** に残してあります。`main` は iPhone 単体版です。訳の質は Mac 版のほうが自然なことが多いです（比較は `docs/ai/DECISIONS.md`）。

> **状態**: シミュレータと自動テストで確認済みです。**iPhone 実機での確認は、これからです**（`docs/ai/IPHONE_DEVICE_CHECKLIST.md`）。Apple 翻訳は、実機でしか動きを確かめられません。

## 必要なもの
- Mac に Xcode（この開発では Xcode 26.1）
- Apple ID（無料でよい。**無料の Apple ID で入れたアプリは 7 日で期限切れ**になり、Mac から入れ直します）
- iPhone（iPhone 17 を想定。iOS 18 以上。Apple 翻訳は iOS 18 以降、Apple Intelligence は iPhone 15 Pro 以降・iOS 26 以降）と USB ケーブル、iPhone の「開発者モード」オン（設定 > プライバシーとセキュリティ）

## 入れ方
1. `ios/Mazemaze.xcodeproj` を Xcode で開く。
2. iPhone を USB でつなぎ、「このコンピュータを信頼」→（「開発者モード」をオン）→ `Signing & Capabilities` の `Team` に自分の Apple ID → 実行先に iPhone を選んで ▶。
3. 初回は、iPhone の「設定 > 一般 > VPN とデバイス管理」で、開発者アプリを「信頼」します。
4. （Xcode のスキームの「Arguments」に `-Mazemaze…` が残っていないことを確認。可能なら Run の Build Configuration を Release に。）

## 使い方
1. アプリを開くと、ホーム画面が出ます。**設定 > 翻訳と意味の作り方**で、ページの翻訳の方法を選びます（既定は Apple 翻訳）。Apple 翻訳は、最初に一度「翻訳データをダウンロード」を押します（システムの確認画面が出ます）。
2. ホームのアドレス欄に記事の URL を入れるか、お気に入りから開きます。**記事のページ**を開くと、画面に見えている本文から順に英語が混ざります。**英語部分をタップすると元の日本語**が出ます。

### 翻訳の方法（設定で選ぶ）
| 方法 | 内容 | 向き不向き |
|---|---|---|
| **Apple 翻訳**（既定） | iOS 標準のオンデバイス翻訳（「翻訳」アプリと同じ仕組み）。日本語→英語のデータを最初に一度ダウンロード | 速くて軽い。句を 1 つずつ訳すため文脈は見ず、直訳寄り |
| **Apple Intelligence** | iOS 26 以降のオンデバイスの言語モデル（Foundation Models）。対応機種で、設定アプリでオンにしている必要があります | 文脈を見て訳せますが、モデルが小さく、固有名詞・慣用句・口語の誤訳があります |

どちらでも、**置き換える場所の選び方・原文の保持・検査は同じ仕組み**です（`ios/MazemazeCore`）。モデルが返した英語は、機械的な検査（日本語の混入、URL・数値の保持、文脈の取り込みなど）を通ったものだけ使い、通らなかった箇所は日本語のままです。ただし、**意味の誤りは検出できません**。迷う句は、英語をタップして原文と見比べてください。

単語・句の意味（「この文での意味（AI）」と、保存した単語の裏での自動検索）は、Apple Intelligence が作ります。使えないときは、設定に理由と次の行動が出ます（標準辞書は、それとは別にいつでも使えます）。

### ホーム画面・タブ・履歴
- 起動すると **Mazemaze のホーム画面**が出ます（特定のサイトは自動で開きません）。ここに、いまの翻訳の状態、**お気に入り**、**最近開いたサイト**があります。Yahoo!ニュースは「おすすめの候補」として「追加」できます。ページを開いて、下のメニュー（⋯）の「お気に入りに追加」でも登録できます（長押しで削除）。
- **検索**: アドレス欄に語句を入れて Go を押すと、その語句が検索サービスに送られ、検索結果のページが開きます（URL はそのまま開きます）。検索エンジンは、設定の「検索」で選べます（既定は Google。Yahoo! JAPAN・Bing・DuckDuckGo）。確認の画面は出ません。
- **タブ**: 下の「タブ」で一覧・新しいタブ・切り替え・閉じる。最大 8 個で、同時に開いたままにするのは 4 個まで（古いタブは休止し、選ぶと読み込み直します）。別のタブを見ている間、そのタブの翻訳は一時停止します。
- **前回のタブの復元**: 起動時に前回のタブを開きます。保存されるのは、ログイン・メール・ネットバンキング・設定画面などを**除いた公開ページの URL（検索条件や認証情報は含まない）**だけです。ページの題名は、翻訳対象サイトのものだけ保存します。
- **履歴を消去**（ホームまたは設定）: 最近のサイトと保存したタブを消します（Cookie やログインは消えません）。設定で「前回のタブを開く」「最近のサイトを記録する」をオフにできます。

### サイトがアプリ内ブラウザを断ったとき
サイトがアプリ内ブラウザを Safari へ誘導したときは、白い画面ではなく「このサイトはアプリ内ブラウザでは開けません」という案内が出ます。「Safari で開く」を押すと Safari で開けます（翻訳はされません）。

**X（x.com / twitter.com）だけは例外**として、アプリ内で開けるようにしています（所有者の判断。個人利用）。X は WKWebView を Safari へ誘導するため、X のページに限り、(1) Safari と同じ形式の UA を送り、(2) Safari が持つ 2 つの目印（`SchemaDataExtractor` / `MicrodataExtractor`）を空の値で用意します。他のサイトには何もしません。設定「X を Safari として開く」でオフにでき、X の利用規約に反する可能性があることは、承知の上で決めたものです。

### 辞書とバーの自動格納
- **辞書**: 英語の部分をタップして出る吹き出しの「**辞書に保存**」を押すと、その英語と元の日本語が辞書に入ります（押したときだけ。自動では集めません。文は保存しません）。下のツールバーの「辞書」から、一覧・検索・メモ・削除・CSV/テキストの書き出しができます。保存先は iPhone の中だけです（端末のバックアップには含まれることがあります）。
- **バー**: アドレス欄は画面の**下**（ツールバーの真上）にあります。ページを下にスクロールすると、アドレス欄とツールバーが隠れて画面が広くなり、上にスクロールすると戻ります。設定「スクロールでバーを隠す」でオフにできます。

### 単語・句の意味を調べる
英語の部分をタップして出る吹き出しで、調べたい**単語を直接タップ**すると「〈単語〉の意味を調べる」が出ます。押すと下からシートが出ます。
- **標準辞書（最初の表示）**: シートの中に、単語・その英語の句・**元の日本語**・単語の並びと、iPhone 内蔵の辞書（設定でダウンロードした英和辞書）の内容が出ます。通信はありません。単語の並びをタップすると、辞書の内容も切り替わります。**特定の辞書（ウィズダムなど）だけを表示することは、アプリからはできません。** 使わない辞書は、設定 > 一般 > 辞書 でダウンロードを解除してください。
- 標準辞書を表示している最中にアプリが落ちたことがあると、次の起動から自動で「ボタンを押したときに別のシートで開く」方式に切り替わります（設定の「標準辞書をシートの中に表示」でオンに戻せます）。
- **この文での意味（AI）**: 上の切り替えで選んだときだけ、iPhone の Apple Intelligence が作ります（**AI が作成。誤りがあるかもしれません**）。その文での意味、原文のどの語にあたるか、ほかの意味、品詞、原形が出ます。「例文・よく使う形を見る」で例文などが追加されます。
- 発音（🔊）は、端末の読み上げ（オフライン）です。音が出ないときは、ボタンの下に理由が出ます。設定 > アクセシビリティ > 読み上げコンテンツ > 声 で、英語の「拡張」「プレミアム」の声をダウンロードすると、自然になります。
- 「句全体の意味を調べる」では、句の意味・ニュアンスが AI で出ます。
- 「辞書に保存」: 単語は、**単語・英語の句・日本語の原文・意味**を 1 つの項目として保存します。標準辞書の画面から保存すると、**意味は、裏で自動で調べて入れます**（翻訳を優先するため、しばらく翻訳がない間に 1 件ずつ）。

### 貼り付けて翻訳
コピーした日本語（X の投稿、Safari の記事の一部など）を、ホームの「貼り付けて翻訳」（またはメニュー ⋯）の画面に貼り付けると、英語混じりにします。英語の部分をタップすると元の日本語、「原文に戻す」で貼り付けた文章に完全に戻ります。4000 文字まで。結果はタブ一覧・履歴・復元に載らず、ディスクにも保存されません。コピーは手動です（X のページを自動で読み取ることはしません）。

### ボタンの意味
- 戻る / 進む、**タブ**（一覧）、吹き出し（**翻訳のオン/オフ**。オフにすると全ページで原文に戻ります）、**辞書**
- **メニュー（⋯）**: Safari で開く、お気に入りに追加、このサイトを翻訳対象に追加、このタブをホームに戻す、新しいタブ、貼り付けて翻訳、設定

### 翻訳されるもの・されないもの
- 初期の対象は `news.yahoo.co.jp`・`x.com`・`twitter.com`（設定やメニューで追加できます。https のみ）。
- ログイン画面、DM、設定、パスワード欄のあるページ、入力欄、コード、**リンクやボタンの文字は翻訳しません**（見出しがリンクになっている一覧ページはあまり変わりません。記事ページを開いてください）。
- 英語化率（目標 10〜70%、既定 30%）は目安です。固有名詞の誤訳は検出できません。

### 安全のために
- 翻訳・辞書・履歴・意味は、iPhone の中だけで処理・保存します。サーバー、アカウント、トークンはありません。
- ページ内の翻訳スクリプトは、ページの JavaScript から見えない領域で動きます。
- 閲覧するサイトのログイン・表示制限は回避しません（X の例外を除く）。
- 設定（翻訳の方法、お気に入り、タブ）は iPhone に保存され、アプリの再起動・上書きインストールでも残ります。アプリを**削除**すると消えます。

### 困ったとき
| 表示・状況 | 対処 |
|---|---|
| 「翻訳の準備が必要です」（ホーム）/ 「翻訳データが未ダウンロードです」 | 設定 > 翻訳と意味の作り方 > 「翻訳データをダウンロード」 |
| 「Apple Intelligence をオンにしてください」 | iPhone の設定アプリ > Apple Intelligence と Siri |
| 「この iPhone は Apple Intelligence に対応していません」 | 設定で、ページの翻訳を Apple 翻訳にする（単語の意味（AI）は使えません。標準辞書は使えます） |
| 何も英語にならない | 記事ページを開く／そのサイトが「翻訳するサイト」に入っているか（メニュー「このサイトを翻訳対象に追加」）／ホームの状態が緑か |
| 画像を写真に保存する | 画像を長押し →「"写真"に追加」。初回に、写真への追加の許可を聞かれます（追加のみで、写真を読み取ることはありません） |
| 「原文はそのままです。もう一度お試しください」 | 再読み込み。続くときは、設定で翻訳の方法を切り替える |

## 開発者向け
ロジックは `ios/MazemazeCore`（Swift パッケージ）、アプリ本体は `ios/Mazemaze`。

```bash
cd ios/MazemazeCore && swift test                      # ロジックのテスト（正解データとの一致を含む）
node ios/WebTests/run_dom_tests.mjs                    # ページ内スクリプトの DOM テスト（実 Chrome）
./ios/scripts/simulator_selftest.sh                    # シミュレータでの通し試験（偽エンジン）
./ios/scripts/persistence_test.sh                      # 設定・お気に入り・タブが再起動・上書き・入れ直しで残るか
python3 ios/tools/generate_project.py                  # ファイルを足したあとの Xcode プロジェクトの再生成
```

選択・検証・表示整形のロジックは、元の Python 実装（ブランチ `mac-local-model`）を基準にしています。基準との一致は `ios/MazemazeCore/Tests/MazemazeCoreTests/Resources/`（`README.md` に再生成の方法）の正解データで確認します。
