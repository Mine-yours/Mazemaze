# mazemaze

日本語の文章の一部を英語に置き換えて読む、個人用のローカル Web アプリです。
文章は **この Mac の中だけ**で処理されます（Ollama 上のローカルモデル `qwen3.5:9b` を使用。外部の AI サービスには送信しません）。

- 英語に置き換えた部分以外の日本語は、一文字も変わりません。
- 変換に失敗した箇所は日本語のまま残ります。
- 英語部分をタップすると、元の日本語が表示されます。

> **状態**: Mac 上での起動と、`localhost` での変換は確認済みです。**iPhone / Android の実機での動作は未確認**です（下の「確認済み・未確認」を参照）。

## 必要なもの

- Apple Silicon の Mac（macOS）
- Python 3.11 以上（`python3 --version` で確認）
- [Ollama](https://ollama.com/)（アプリを起動しておく）
- モデル `qwen3.5:9b`（導入済みか `ollama list` で確認）

## セットアップ（初回だけ）

ターミナルを開き、このフォルダで次を実行します。

```bash
cd /Users/mineno/project/app/mazemaze
python3 -m venv .venv                         # すでに .venv があれば不要
.venv/bin/pip install -r requirements.txt     # FastAPI と uvicorn
ollama list                                   # qwen3.5:9b が表示されることを確認
```

`qwen3.5:9b` が表示されない場合は、`ollama pull qwen3.5:9b` で導入します（このアプリは自動では導入しません）。

## 起動（この Mac だけで使う）

```bash
./scripts/run_local.sh
```

ブラウザで <http://localhost:8000> を開きます。止めるときはターミナルで `Ctrl-C` です。

1. 文章を入力する（1000 文字まで）
2. 「英語化率の目安」と「置き換える単位」を選ぶ
3. 「変換する」を押す（初回はモデルの読み込みで数十秒かかることがあります。**処理中は中断できません**）
4. 英語部分を押すと元の日本語、「結果をコピー」でコピー、「元の文章に戻す」で原文表示

「英語化率」は目標値で、保証ではありません（空白・句読点を除く元の文字数に対する、置き換え元の長さの割合）。

## スマホから使う（同じ Wi-Fi の中。外出先は下の Tailscale）

```bash
./scripts/run_lan.sh
```

`run_lan.sh` は、既定で **暗号化（自己署名の TLS）付き**で起動し、iPhone アプリ用の QR を表示します。スマホの「ブラウザ」で Web 版を使う場合は、`MAZEMAZE_TLS=0 ./scripts/run_lan.sh`（暗号化なしの HTTP）で起動し、表示された `http://192.168.x.x:8000/#t=…` を開きます（暗号化ありのままブラウザで開くと、自己署名のため証明書の警告が出ます）。

### 安全上の注意（必ず読んでください）

- このモードは Mac を同じネットワークの機器から使えるようにします。**自宅など信頼できるネットワークでだけ**使い、カフェ・職場・学校の共有 Wi-Fi では使わないでください（外出先では、共有 Wi-Fi に直接つながず、下の Tailscale を使ってください）。
- **インターネットへ公開しないでください。** ルーターのポート転送、ngrok などの公開トンネルは使わないでください。
- アプリには次の保護を入れています。**暗号化なしの HTTP（`MAZEMAZE_TLS=0`）では**、同じネットワーク内の人に通信（翻訳する文章とトークン）を見られる可能性があります。既定の暗号化あり（iPhone アプリ）では、ペアリングした証明書の Mac にだけ接続します。
  - 同じネットワーク（プライベート IP）からのアクセスだけを許可
  - アクセストークン（URL の `#t=` の部分。トークンを知らないと変換できません。`run_lan.sh` では `.mazemaze_token` に保存され、削除すると新しく作られます）
  - 想定外のホスト名・別サイトからのリクエストを拒否
  - 変換は 1 件ずつ（Mac に負荷をかけすぎないため）
- Ollama 自体（ポート 11434）は LAN に公開しません。スマホからは必ずこのアプリ経由です。
- URL（トークン付き）を人に送らないでください。使い終わったら `Ctrl-C` で止めてください。
- `MAZEMAZE_NO_TOKEN=1 ./scripts/run_lan.sh` でトークンなしにもできますが、おすすめしません。
- Mac のファイアウォールが有効な場合、初回に「着信接続を許可しますか」と表示されることがあります。このアプリ（Python）に対してだけ許可してください。

### 外出先から使う（Tailscale、iPhone アプリ + 暗号化あり）

家の外では、Mac と iPhone の両方で [Tailscale](https://tailscale.com/) をオンにすると、同じアプリ・同じ QR で使えます。通信は Tailscale の暗号化の中を通り、そのうえで Mazemaze の TLS（証明書の指紋の確認）とトークンも使います。**tailnet（自分の Tailscale ネットワーク）の中だけ**に届き、インターネットには公開されません。

1. Mac と iPhone に Tailscale を入れ、同じアカウントでログインする（無料のプランで足ります）。
2. Mac で `./scripts/run_lan.sh` を起動する。Tailscale が動いていれば、QR に外出先用の名前（`<Mac>.<tailnet>.ts.net`）が入り、画面に「tailnet からの転送」の状態が出る。
3. 転送が未設定と出たら、Mac で**一度だけ**表示されたコマンドを実行する: `tailscale serve --bg --tcp=8000 tcp://localhost:8000`（やめるときは `tailscale serve --tcp=8000 off`）。`run_lan.sh` は Tailscale の設定を変更しません。
4. iPhone で QR を読み取り直し、確認画面の「外出先（Tailscale）」の行を確かめて承認する（初回だけ）。
注意: iPhone は **IP ではなく Tailscale の名前**で接続します（iOS の制限（ATS）のため、アプリは `*.ts.net` の名前にだけ例外を入れています）。Tailscale の MagicDNS を有効のままにしてください（既定で有効）。
5. 家では今までどおり（`.local` → IP の順）、外では Tailscale 経由で自動的に切り替わります。外で最初の接続は数秒かかることがあります。

守ること:
- **Tailscale Funnel（インターネット公開）は使わないでください。** Mazemaze のポートは `serve`（tailnet 内だけ）で転送します。`run_lan.sh` は Funnel が有効なら警告します。
- 転送を設定しないかぎり、tailnet の端末が Mac のポートへ直接つないでも拒否されます（Tailscale のアドレスは「同じ LAN」とは扱いません）。
- tailnet に他人の端末を入れていないか、Tailscale の管理画面で確認してください（共有・ACL）。端末の鍵の有効期限が切れると繋がらなくなるので、管理画面で確認・延長してください。
- 外出先でも、Mac は起動していて、スリープしていない必要があります。
- Mac を止めたあとは、`tailscale serve --tcp=8000 off` で転送を外せます。

スマホでは、HTTP の LAN アドレスだと「ホーム画面に追加（インストール可能な PWA）」はできません（HTTPS または localhost が必要なため）。ブラウザで開いて使います。

## iPhone アプリ（個人用ブラウザ）

Mazemaze には、**自分の iPhone に Xcode から入れて使う専用ブラウザアプリ**があります（`ios/`）。アプリの中のブラウザで Yahoo!ニュースなどを普通に見ると、本文の日本語の一部が英語に置き換わります。翻訳は同じ Wi-Fi にある **Mac の Ollama（ローカルモデル）だけ**で行い、インターネット上の翻訳サービスには送りません。App Store には出しません。

> **状態**: iPhone 実機で動作を確認済み（初版）。今回の更新（ホーム画面・タブ・QR ペアリング・暗号化・翻訳の高速化）は、シミュレータと自動テストで確認済みで、**実機での確認はこれから**です（`docs/ai/IPHONE_DEVICE_CHECKLIST.md`）。

### iPhone だけで使う（Mac なし。任意）

設定の「翻訳と意味の作り方」で、**ページの翻訳**と**単語・句の意味**を、それぞれ「Mac」か「iPhone」から選べます（既定は今までどおり Mac）。

| 方法 | 内容 | 向き不向き |
|---|---|---|
| Mac（ローカルモデル） | Mac の Ollama（Qwen3.5 9B）。LAN / Tailscale 経由 | 今までどおり。訳が自然なことが多い |
| iPhone: Apple 翻訳 | iOS 標準のオンデバイス翻訳（日本語→英語のデータを最初に一度ダウンロード） | 速く軽い。句を 1 つずつ訳すため文脈は見ない |
| iPhone: Apple Intelligence | iOS 26 以降のオンデバイスの言語モデル（対応機種で、設定でオン） | 翻訳と、単語・句の意味カードに使える。モデルが小さく、訳や意味の質は Mac より落ちる |

- iPhone を選んだ処理は、Mac も通信も使わず、文章は iPhone の外に出ません（Apple の Private Cloud Compute などのクラウドも使いません）。
- どの方法でも、**置き換える場所の選び方・原文の保持・検査は同じ仕組み**（Mac のサーバーと同じロジックを Swift に移したもので、Python と同じ結果になることを数千件のテストで確認しています）。検証できなかった箇所は日本語のままです。
- 「Mac に繋がらないとき、iPhone で処理する」を入れると、Mac に届かないとき（外出先で Tailscale が切れている等）だけ iPhone の方法に切り替わります。トークンや証明書の問題は隠さず、そのまま表示します。
- 単語の意味は、標準辞書（iPhone の辞書）が主です。「この文での意味（AI）」を iPhone の Apple Intelligence で作ることもできます。
- Apple 翻訳のデータは、設定の「翻訳データをダウンロード」から入れます（システムの確認画面が出ます）。

### 必要なもの
- Mac に Xcode（App Store から。この開発では Xcode 26.1 を使用）
- Apple ID（無料でよい。**無料の Apple ID で入れたアプリは 7 日で期限切れ**になり、Mac から入れ直します）
- iPhone（iOS 17 以上）と USB ケーブル、iPhone の「開発者モード」オン（設定 > プライバシーとセキュリティ）
- 上の「セットアップ」を済ませた Mac（Ollama と `qwen3.5:9b`）

### 手順
1. **Mac でサーバーを起動**する（iPhone と同じ Wi-Fi。ゲスト Wi-Fi や VPN、AP 分離の Wi-Fi は不可）:
   ```bash
   ./scripts/run_lan.sh
   ```
   ターミナルに **QR コード**が表示されます（初回は暗号化用の証明書を作るので数秒かかります）。Mac のファイアウォールが「受信接続を許可しますか」と聞いたら許可します。Mac がスリープすると切れるので、使う間は `caffeinate -i ./scripts/run_lan.sh` が便利です。
2. **Xcode でアプリを入れる**: `ios/Mazemaze.xcodeproj` を開く → iPhone を USB でつなぎ、「このコンピュータを信頼」→（「開発者モード」をオン）→ `Signing & Capabilities` の `Team` に自分の Apple ID → 実行先に iPhone を選んで ▶。初回は iPhone の「設定 > 一般 > VPN とデバイス管理」で開発者アプリを「信頼」します。`Bundle Identifier` が重複と言われたら、末尾を変えます。
3. **ペアリング（初回だけ）**: アプリを開くと設定が自動で開きます。**iPhone の標準「カメラ」アプリで、Mac の QR を読み取り**、出てきた通知をタップします。確認画面（Mac の名前、アドレス、暗号化あり、証明書の指紋）を見て **「ペアリングする」**を押します。初回は「ローカルネットワークの検索と接続を許可」を**許可**します（許可の直後は確認が失敗することがあるので、アプリが自動で 1 回やり直します。それでも緑にならなければ、ホーム画面の「もう一度確認」を押します）。
   - QR を読み取れないときは、ターミナルに出ている `mazemaze://pair?…` の 1 行をコピーし、アプリの「設定 > ペアリング」の貼り付けボタンを押します。
   - QR は Mac の画面から iPhone のカメラに**直接**渡るので、トークンが Wi-Fi 上を流れません。
4. **使う**: ホーム画面のアドレス欄に記事の URL を入れるか、お気に入りから開きます。**記事のページ**を開くと、画面に見えている本文から順に英語が混ざります（長い段落は、前半が訳せた時点で先に反映されます）。**英語部分をタップすると元の日本語**が出ます。

### ホーム画面・タブ・履歴
- 起動すると **Mazemaze のホーム画面**が出ます（特定のサイトは自動で開きません）。ここに、Mac との接続状態（暗号化の有無つき）、**お気に入り**、**最近開いたサイト**があります。Yahoo!ニュースは「おすすめの候補」として「追加」できます。ページを開いて、下のメニュー（⋯）の「お気に入りに追加」でも登録できます（長押しで削除）。
- **検索**: アドレス欄に語句を入れると、その語句が外部の検索サービス（DuckDuckGo）に送られます。送る前に必ず確認が出ます（URL はそのまま開きます。日本語のドメインなど URL と判断できない入力は検索として扱います）。
- **タブ**: 下の「タブ」で一覧・新しいタブ・切り替え・閉じる。記事内のリンク（`target=_blank`）や `window.open` は新しいタブで開きます。最大 8 個で、同時に開いたままにするのは 4 個まで（古いタブは休止し、選ぶと読み込み直します）。タブを切り替えても、開いたままのタブは再読み込みされません。別のタブを見ている間、そのタブの翻訳は一時停止します。
- **前回のタブの復元**: 起動時に前回のタブを開きます。保存されるのは、ログイン・メール・ネットバンキング・設定画面・LAN の機器などを**除いた公開ページの URL（検索条件や認証情報は含まない）**だけです。それ以外のタブはホーム画面として復元されます。ページの題名は、翻訳対象サイトのものだけ保存します。
- **履歴を消去**（ホームまたは設定）: 最近のサイトと保存したタブを消します（Cookie やログインは消えません）。設定で「前回のタブを開く」「最近のサイトを記録する」をオフにできます。保存されたものは iPhone のバックアップに含まれることがあります。

### 暗号化とペアリングの仕組み（なりすまし対策）
- `run_lan.sh` は、Mac に自己署名の証明書を一度だけ作り（`.mazemaze_tls/`、Git 管理外）、その **SHA-256 指紋を QR に入れます**。アプリはその証明書と**同じものを提示した Mac にだけ**接続し、違うものなら**何も送らずに**拒否します（トークンも本文も送りません）。IP アドレスが変わっても、指紋が同じなら接続できます。
- アドレスは「Mac の名前（`〇〇.local`）」を先に使い、見つからなければ IP アドレスを使います（暗号化なしの HTTP でも同じ）。2 つの候補があるときは、トークンを送る前に「Mazemaze のサーバーとして応答する相手」かを確認し、その相手にしか送りません（候補が 1 つのときは確認なしで接続します）。HTTPS では加えて証明書の指紋も一致する必要があります。
- 証明書を作り直した（`.mazemaze_tls/` を消した）場合は、QR を読み取り直します。手入力の `https://` では証明書を確認できないため、使えません。
- 暗号化を使わない旧方式は `MAZEMAZE_TLS=0 ./scripts/run_lan.sh`（HTTP。手入力の URL とトークン）です。同じ Wi-Fi の人に通信を見られる可能性があります。

### 翻訳が出るまでの時間
実機に近い条件（シミュレータ、実 Qwen3.5:9b、Yahoo!ニュースの実記事）で、ページ読み込み完了から最初の翻訳が表示されるまで:

| 条件 | 改善前 | 改善後 |
|---|---|---|
| モデルが温まっている（記事 A） | 4.9 秒 | 約 1.1 秒 |
| 同（記事 B） | 5.1 秒 | 約 1.7 秒 |
| モデルが冷えている（アプリ起動と同時に準備） | 7.9 秒 | 約 4.6 秒 |

主な改善: 開始待ちの短縮、長い段落の部分反映（約 160 文字ごとに分け、できた部分から表示）、1.5 画面先までの先読み、モデルの事前準備（`/api/warmup`、30 分保持）、重複の再送防止。1 回の翻訳（約 100 文字）自体は 2 秒前後で、モデルの速度に依存します（Mac 側を並列化しても改善は小さいことを確認済み）。

### サイトがアプリ内ブラウザを断ったとき
サイトがアプリ内ブラウザを Safari へ誘導したときは、白い画面ではなく「このサイトはアプリ内ブラウザでは開けません」という案内が出ます。「Safari で開く」を押すと Safari で開けます（翻訳はされません）。

**X（x.com / twitter.com）だけは例外**として、アプリ内で開けるようにしています（所有者の判断。個人利用）。X は WKWebView を Safari へ誘導するため、X のページに限り、(1) Safari と同じ形式の UA を送り、(2) Safari が持つ 2 つの目印（`SchemaDataExtractor` / `MicrodataExtractor`）を空の値で用意します。他のサイトには何もしません。設定「X を Safari として開く」でオフにできます（変更は新しいタブから）。X の利用規約には、公開インターフェース以外の利用や自動アクセスの禁止があります。使うのは自己責任で、ログインや投稿の自動化・取得はしません。X が仕様を変えると、また誘導される（案内カードが出る）ことがあります。実機での表示・ログインは未確認です。

### 辞書とバーの自動格納
- **辞書**: 英語の部分をタップして出る吹き出しの「**辞書に保存**」を押すと、その英語と元の日本語が辞書に入ります（押したときだけ。自動では集めません。文は保存しません）。下のツールバーの「辞書」から、一覧・検索・メモ・削除・CSV/テキストの書き出しができます。保存先は iPhone の中だけで、Mac やクラウドには送りません（端末のバックアップには含まれることがあります）。
- **バー**: アドレス欄は画面の**下**（ツールバーの真上）にあります（スクロールしないページで上が邪魔にならないように）。アドレス欄をタップすると、ツールバーが引っ込んで、キーボードのすぐ上に出ます。ページを下にスクロールすると、アドレス欄とツールバーが隠れて画面が広くなり、上にスクロールすると戻ります（画面下の「localhost」のような小さな表示を押しても戻ります）。設定「スクロールでバーを隠す」でオフにできます。翻訳の状態は、翻訳ボタンの回転表示と件数で分かります。問題があるときは、赤い帯が出てバーも戻ります。

### 単語・句の意味を調べる
英語の部分をタップして出る吹き出しで、調べたい**単語を直接タップ**すると「〈単語〉の意味を調べる」が出ます（`I have a pen` の `have` など）。押すと下からシートが出ます。
- **標準辞書（最初の表示。押さなくても内容が出ます）**: シートの中、単語・その英語の句・**元の日本語（センテンス）**・単語の並びの下に、iPhone 内蔵の辞書（設定でダウンロードした英和辞書）の内容がそのまま出ます。通信はなく、Mac も使いません。辞書の意味のうちどれにあたるかを、上の原文を手がかりに選べます。単語の並びをタップすると、辞書の内容も切り替わります。英和辞書が未ダウンロードのときは、辞書の部分にダウンロードの案内が出ます（その場合は上の「この文での意味（AI）」に切り替えてください）。
- **特定の辞書（ウィズダム英和辞典など）だけを表示することは、アプリからはできません。** iPhone は、ダウンロード済みの辞書をすべて表示し、アプリが辞書を選んだり内容の文字を取り出したりする方法を用意していません。ウィズダムだけにしたいときは、**設定 > 一般 > 辞書 で、使わない辞書（Oxford 系など）のダウンロードを解除**してください（画面の名称は iOS のバージョンで違うことがあります）。残した辞書だけが、このシートにも出ます。
- 標準辞書を表示している最中にアプリが落ちたことがあると、次の起動から自動で「ボタンを押したときに別のシートで開く」方式に切り替わり、理由が出ます（設定の「標準辞書をシートの中に表示」でオンに戻せます。また落ちたら、再びオフになります）。
- **この文での意味（AI）**: 上の切り替えで選んだときだけ Mac のローカルモデル（Qwen3.5:9b）に聞きます（**AI が作成。誤りがあるかもしれません**。数秒かかります）。その文での意味、原文のどの語にあたるか、ほかの意味、品詞、原形が出ます。「例文・よく使う形を見る」を押すと、例文などが追加されます。Mac が起動していて、同じ Wi-Fi にあることが必要です。
- 発音（🔊）、シートの単語の並び（`I` `have` `a` `pen` と「句全体」。タップで別の単語に切り替え）は、どちらの表示でも使えます。
- 「句全体の意味を調べる」では、句の意味・ニュアンスが AI で出ます（辞書は使いません）。
- 「辞書に保存」: 単語は、**単語・英語の句（原文の英語）・日本語の原文・意味**の 4 つを 1 つの項目として保存します。標準辞書の画面から保存すると、**意味は、裏で自動で調べて入れます**（Mac のローカルモデル。翻訳を優先するため、しばらく翻訳がない間に 1 件ずつ調べます。Mac が止まっているときは、あとで自動でやり直します。調べている間は一覧に「意味を調べています…」と出ます）。AI の画面から保存したときは、最初から意味が入ります。設定の「保存した単語の意味を、裏で自動で調べる」でオフにできます。取得に失敗した項目は、項目を開いて「もう一度、自動で調べる」で再試行できます。「詳しい意味」（例文・よく使う形など）は、項目から「意味を調べる」で足せます。
- **Mac のサーバーを更新したら、再起動が必要です。** 「意味を調べられませんでした」と出て「Mac のサーバーが古いようです」と表示されるときは、Mac のターミナルで `run_lan.sh` を止めて（Ctrl+C）、もう一度 `caffeinate -i ./scripts/run_lan.sh` を実行してください（`/api/define` は新しい版のサーバーにだけあります）。
- 🔊 を押しても音が出ないときは、ボタンの下に理由（英語の音声がない、再生を始められない）が出ます。音量、Bluetooth の接続先、設定 > アクセシビリティ > 読み上げコンテンツ > 声 で英語の声をダウンロード済みか、を確認してください。

### 貼り付けて翻訳
コピーした日本語（X の投稿、Safari の記事の一部など）を、ホームの「貼り付けて翻訳」（またはメニュー ⋯）の画面に貼り付けると、英語混じりにします。英語の部分をタップすると元の日本語、「原文に戻す」で貼り付けた文章に完全に戻ります。4000 文字まで。結果はタブ一覧・履歴・復元に載らず、ディスクにも保存されません（閉じると画面から消えます。翻訳の一時的な控えは、アプリのメモリにだけ残り、アプリを終了すると消えます）。コピーは手動で、ページの自動取得はしません。ショートカットアプリから `mazemaze://paste` を開くと、この画面が開きます（本文は URL に載せず、貼り付けボタンで入れます）。

### ボタンの意味
- 戻る / 進む、**タブ**（一覧）、吹き出し（**翻訳のオン/オフ**。オフにすると全ページで原文に戻り、以後送信しません）
- 左向き矢印「**原文に戻す**」: **このページだけ**原文に戻します。押すと「再翻訳」に変わります
- **メニュー（⋯）**: Safari で開く、お気に入りに追加、このサイトを翻訳対象に追加、このタブをホームに戻す、新しいタブ、設定（サーバー・英語化率・置き換える単位・翻訳するサイト・タブと履歴）

### 翻訳されるもの・されないもの
- 初期の対象は `news.yahoo.co.jp`・`x.com`・`twitter.com`（設定やメニューで追加できます。https のみ）。
- ログイン画面、DM、設定、パスワード欄のあるページ、入力欄、コード、**リンクやボタンの文字は翻訳しません**（見出しがリンクになっている一覧ページはあまり変わりません。記事ページを開いてください）。
- 英語化率は目安です。固有名詞の誤訳は検出できません。

### 安全のために（必ず読んでください）
- 外部公開・ポート転送・トンネルは使わないでください。サーバーには、アクセストークン、同じネットワークの機器だけを許す IP 検査、ホスト名の検査があります。
- アプリは、接続先として **Mac / ローカルネットワークのアドレスだけ**を受け付けます（インターネット上のアドレスは入力できません）。リダイレクトも追いません。
- アクセストークンは iPhone のキーチェーンに保存され、閲覧中のページの JavaScript には渡りません。ページ内の翻訳スクリプトはページの JavaScript から見えない領域で動き、通信はすべてアプリ側（Swift）が行います。
- `mazemaze://pair?…` のリンクは、他のアプリや Web ページからも開けてしまうため、**確認画面で「ペアリングする」を押すまで何も変わりません**。心当たりのない QR やリンクは使わないでください。
- 閲覧するサイトのログイン・表示制限は回避しません。
- 設定（サーバー、証明書の指紋、お気に入り、タブ）は iPhone に保存され、アプリの再起動・上書きインストールでも残ります（確認済み）。アプリを**削除**すると、設定とお気に入りは消えますが、トークンはキーチェーンに残ります（再ペアリングで上書きされます）。

### 困ったとき
| 表示 | 対処 |
|---|---|
| 「Mac に接続できません」 | Mac で `run_lan.sh` が動いているか、Mac がスリープしていないか、同じ Wi-Fi か（ゲスト Wi-Fi・VPN は不可）、iPhone の「設定 > Mazemaze > ローカルネットワーク」が許可か。ホームの「もう一度確認」 |
| 「トークンが違います」 | Mac の QR をもう一度カメラで読み取る |
| 「Mac の証明書が、ペアリングしたときと違います」 | 別の機器になりすまされているか、Mac 側で証明書を作り直しました。信頼できるなら QR を読み取り直す |
| 「暗号化接続（https）の証明書を確認できません」 | 手入力の `https://` は使えません。QR か貼り付けでペアリング |
| 「Mac の Ollama が起動していません」 | Mac で Ollama アプリを起動 |
| 「Mac が他の翻訳を処理中です」 | 他の変換が終わるのを待つ（自動で続きます） |
| 「エラーが続いたため停止します」 | 約 30 秒後に自動で再開します。Mac 側の状態を確認 |
| 何も英語にならない | 記事ページを開く／ホームで接続が緑か／そのサイトが「翻訳するサイト」に入っているか（メニュー「このサイトを翻訳対象に追加」） |

### 開発者向け
- 純ロジック（接続先・サイト・ペアリング・ピン留め・履歴の判定、直列キュー、タブ別の世代、キャッシュなど）は `ios/MazemazeCore`（Swift Package）: `cd ios/MazemazeCore && swift test`

- 翻訳待ち時間の計測（実 Ollama・実ページ）: `ios/scripts/bench.sh <URL> [秒数]`（`COLD=1` でモデルを降ろして測定）
- 設定の保存確認（再起動・更新インストール・入れ直し）: `ios/scripts/persistence_test.sh`
- プロジェクトファイルの再生成: `python3 ios/tools/generate_project.py`

## 設定（環境変数・任意）

| 変数 | 既定値 | 意味 |
|---|---|---|
| `MAZEMAZE_MODEL` | `qwen3.5:9b` | 使うモデル。`qwen3.5:9b` または `translategemma:12b` のみ許可。それ以外（クラウド版を含む）は起動時に拒否 |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Ollama の場所。この Mac（loopback）のみ許可 |
| `MAZEMAZE_CALL_TIMEOUT` | `120` | Ollama 1 回の呼び出しの制限時間（秒） |
| `MAZEMAZE_DEADLINE` | `180` | 1 回の変換全体の目安の制限時間（秒。バッチ間で確認） |
| `PORT` | `8000` | ポート番号 |

例: `MAZEMAZE_MODEL=translategemma:12b ./scripts/run_local.sh`（手動で切り替える場合。モデルの切り替え直後は読み込みで遅くなります）

## テスト

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

テストは実際の Ollama には接続しません（ネットワーク遮断あり）。

iPhone 版のロジック（`ios/MazemazeCore/.../OnDevice/`）は、Python の `backend/` を基準にしています。Python 側を変えたら、正解データを作り直してから Swift のテストを回してください。

```bash
.venv/bin/python scripts/gen_ondevice_golden.py     # 正解データ（ios/MazemazeCore/Tests/.../Resources/ondevice_golden.json）
cd ios/MazemazeCore && swift test                    # Swift の出力が Python と一致するか
```

## うまく動かないとき

| 表示 | 対処 |
|---|---|
| 「Ollama に接続できません」 | Ollama アプリを起動する。`curl http://127.0.0.1:11434/api/version` で確認 |
| 「モデルが見つかりません」 | `ollama list` を確認。なければ `ollama pull qwen3.5:9b` |
| 「ローカルモデルとして確認できない」 | モデルが別名・クラウド版の可能性があります。`ollama list` を確認 |
| 「別の変換を処理中です」 | 前の変換が終わるまで待ってから再試行 |
| 「時間内に終わりませんでした」 | 文章を短くして再試行。初回はモデル読み込みで遅いことがあります |
| 結果の一部が日本語のまま | 検証に通らなかった箇所は安全のため日本語のまま残します（数字・英字・URL を含む部分は最初から対象外） |
| スマホで開けない | Mac とスマホが同じ Wi-Fi か、URL の IP とトークンが正しいか、Mac のファイアウォール設定を確認 |

## 仕組みと制約

- アプリが日本語を文・節に分け、置き換える箇所を決定的に選びます（同じ入力・設定なら同じ箇所）。LLM には選んだ部分の翻訳だけを依頼し、結果を検証してから採用します。
- 固有名詞（人名・店名など）の誤訳は検出できません。英語化率は目安です。
- Ollama のサーバー側にクラウド機能があり、有効な場合はこのアプリからは検出できません。ローカル専用にするには `~/.ollama/server.json` に `{"disable_ollama_cloud": true}` を書いて Ollama を再起動します（手順は `eval/README.md`）。確認: `grep "Ollama cloud disabled" ~/.ollama/logs/server.log | tail -1` が `true`。このアプリは設定を変更しません。
- 1 つの変換は 1000 文字まで、置き換える箇所は 24 個までです。
- 暗号化付きで起動すると（`run_lan.sh` の既定）、Mac のブラウザで Web 版を使うときは `./scripts/run_local.sh`（localhost、HTTP）を使ってください。LAN 側は iPhone アプリ用です。
- 翻訳の待ち時間を短くするため、サーバーはモデルを 30 分保持し（`keep_alive`）、アプリが起動時・復帰時に `POST /api/warmup`（本文を含まない軽い要求。認証必須）でモデルを準備します。
