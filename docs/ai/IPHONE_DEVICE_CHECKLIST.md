# iPhone 実機での確認チェックリスト（v2: ホーム・タブ・ペアリング・高速化）

実機でしか分からない項目です。シミュレータ・自動テストで確認済みのことは `docs/ai/STATE.md` を参照。
各項目に結果（OK / NG とメモ）を書き込んでください。NG のときは、画面下の赤い表示（接続先とエラー内容）と、Mac のターミナルの最後の数行を控えると原因を特定できます。

## 0. 準備（Mac）
- [ ] `caffeinate -i ./scripts/run_lan.sh` を実行（初回は暗号化用の証明書を作る）。ターミナルに **QR** と `mazemaze://pair?…` の 1 行が出る。ターミナルを暗い背景にしていても QR が出る（**カメラで読めるか**は §2 で確認）。
- [ ] （別のターミナルで）`./scripts/run_local.sh` を起動し、Mac のブラウザで `http://localhost:8000` が動く＝Ollama・モデルが正常（確認できたら止める。`run_lan.sh` と同時には使わない）。

## 1. インストール
- [ ] iPhone の「デベロッパモード」をオン（Xcode につないだあとに「設定 > プライバシーとセキュリティ」に現れる。再起動が必要）。
- [ ] Xcode で Team を選んで ▶。無料 Apple ID は 7 日で失効（失効後に**上書きで入れ直すと設定は残る**。**アプリを削除すると設定・お気に入りは消え、トークンだけキーチェーンに残る**ので、再ペアリングが必要）。iPhone の「VPN とデバイス管理」で信頼。
- [ ] **Xcode のスキームの「Arguments」に `-Mazemaze…` が残っていないこと**（Product > Scheme > Edit Scheme > Run > Arguments）。可能なら Run の Build Configuration を **Release** にして確認（Debug は検証用の機能が入っている）。
- [ ] 初回起動で設定画面が自動で開く（未設定のため）。「ペアリング」が先頭にあり、QR の案内が読める。

## 2. ペアリング（最重要）
- [ ] iPhone の標準「カメラ」で Mac の QR を読み取る → 通知をタップ → **確認画面**（Mac の名前、アドレス、予備のアドレス、暗号化あり、証明書の指紋の先頭 16 桁）が出る。**設定画面が開いたままでも確認画面が出る**（出ない場合は NG）。指紋が Mac の表示（`証明書の指紋 …`）の先頭と一致する。
- [ ] 「ペアリングする」→ **ローカルネットワーク許可ダイアログ** → 「許可」。直後の確認が失敗しても、自動で 1 回やり直され、ホーム画面の接続カードが緑（「Mac に接続できています」＋「通信は暗号化されています」）になる。
- [ ] 許可を拒否した場合: 赤いメッセージにエラーコード（-1009 / -1004 など。**どのコードになるかを記録**）と「ローカルネットワーク」の案内が出る。設定アプリでオンにしてアプリに戻ると、ホームの接続カードが自動で更新される。
- [ ] QR を読み取れない場合の代替: Mac の `mazemaze://pair?…` の 1 行をコピー → 設定 > ペアリングの貼り付けボタン → 同じ確認画面が出る（貼り付けの許可プロンプトが出る）。
- [ ] 心当たりのない `mazemaze://pair?…` を開く（例: メモに書いて自分でタップ）→ **確認画面で止まり、押すまで何も変わらない**。キャンセルで何も変わらない。
- [ ] 設定を閉じてアプリを終了→起動し直しても、接続が残る（キーチェーンと設定）。
- [ ] ペアリング済みの状態で設定を開いて何も変えずに「完了」→ ピン留め・予備アドレスが消えない（接続カードが暗号化ありのまま）。
- [ ] 手入力で `https://（Mac の IP）:8000` を保存して接続確認 → **「暗号化接続の証明書を確認できません。QR か貼り付けで…」**と出る（手入力 https は使えない）。
- [ ] Mac で `.mazemaze_tls/` を消して `run_lan.sh` を再起動（証明書が変わる）→ アプリは「証明書がペアリングしたときと違います」と出し、**Mac のターミナルに翻訳のリクエストが出ない**。QR を読み取り直すと復旧。
- [ ] Wi-Fi を切る／別の Wi-Fi／`run_lan.sh` を止める／Mac をスリープ → それぞれ原因別の文言。Wi-Fi の IP が変わった場合（Mac を別の Wi-Fi にする等）、`〇〇.local` 名または保存した IP で自動的に繋がる（繋がらない場合は QR を読み取り直す）。

## 3. 翻訳（Yahoo!ニュースの記事ページ）と速さ
- [ ] ホームの「おすすめ」から Yahoo!ニュースを開き、記事を開く → **読み込み完了から約 1〜2 秒で最初の英語が出る**（モデルが温まっているとき）。体感を記録（何秒か）。
- [ ] 長い段落は、前半が先に英語になり、後半が少し遅れて続く。
- [ ] スクロールすると、新しく見える本文が続けて翻訳される（止まらない）。下の方は先読みで、見る前に訳されていることが多い。
- [ ] 下部の状態行: 「翻訳中…」→「翻訳: オン」、「英語化 N 箇所」が増える。
- [ ] 最初の 1 件（アプリを開いて最初の記事）が、Mac を放置したあとでも極端に遅くない（起動時の事前準備の効果。遅い場合は何秒かを記録）。
- [ ] リンク・ボタン・コメント欄・入力欄は変わらない。リンクをタップして遷移できる。翻訳中でもスクロール・リンク操作ができる。
- [ ] 一覧ページ（トップ）では、9 秒後に「翻訳できる本文が見つかりません」と出る（ページに article/main 配下のリンク以外の日本語があると出ない。出なくても異常ではない）。

## 4. 原文表示・復元
- [ ] 英語部分をタップ → 元の日本語のポップオーバー（複数行にまたがる句でも、タップした位置の近く）。別の場所をタップで閉じる。画面の下端・端でも見切れない。
- [ ] 「原文に戻す」→ そのページだけ元の日本語になり、ボタンが「再翻訳」に変わる。「再翻訳」で再び英語混じり。
- [ ] 吹き出しをオフ → 全ページ原文、送信が止まる（Mac のターミナルに POST が出ない）。オンで再開。
- [ ] 記事を戻る/進む、別の記事へ遷移 → 古い訳が混ざらない。

## 5. ホーム画面・お気に入り・履歴・検索
- [ ] 起動直後は **Mazemaze のホーム画面**（Yahoo!ニュースなどが勝手に開かない）。接続カード、お気に入り（空の状態の文言）、おすすめ候補、最近のサイト（空の状態）、検索についての説明が読める。
- [ ] 「おすすめ」の「追加」→ お気に入りに入る。ページを開いてメニュー（⋯）「お気に入りに追加」→ 入る（ログイン系のページは断られる）。お気に入りを長押し → 削除。VoiceOver でも「お気に入りから削除」が使える。
- [ ] 記事を開いてホームに戻ると、「最近開いたサイト」に載る（クエリ・認証情報を含まない URL）。「履歴を消去」→ 確認が出て、最近のサイトが消える。
- [ ] アドレス欄に **語句**（例: 東京の天気）を入れて Go → **「DuckDuckGo に送られます」の確認**が出る。キャンセルで何も送られない。URL（`x.com`）はそのまま開く。日本語のドメインらしい入力も検索の確認になる。
- [ ] `javascript:alert(1)` などを入れると「開けません」と出る。

## 6. タブ
- [ ] メニュー「新しいタブ」/ タブ一覧の「＋」→ ホーム画面の新しいタブ。切り替えても、**開いたままのタブは再読み込みされない**（スクロール位置・入力が残る）。
- [ ] 記事内のリンク（`target=_blank` のもの）をタップ → 新しいタブで開く（あれば）。
- [ ] 8 個まで作る → 9 個目は「タブは最大 8 個」と出る（一覧の「＋」は無効）。5 個目以降を作ると古いタブが「休止中」になり、選ぶと読み込み直して開く。
- [ ] タブ一覧のカードに「翻訳中／エラー／原文表示／休止中」が出る。×で閉じる。最後の 1 個を閉じてもホームのタブが残る。
- [ ] 別のタブへ切り替えると、前のタブの翻訳は止まり、戻ると続く。
- [ ] アプリを終了して起動し直す → 前回のタブが戻る（公開ページの URL のみ。ログイン・メール等はホームとして戻る）。設定で「起動時に前回のタブを開く」をオフにすると戻らない。「履歴を消去」後に再起動しても、消した内容が戻らない（消去後に開き直したタブは別）。

## 7. サイトの制限・案内
- [ ] アドレス欄に `x.com` → 「アプリ内ブラウザでは開けません」の案内が出るか、通常のページ／ログイン画面が出るか（**どちらだったかを記録**。X の挙動は実機で未確認）。案内が出たら:「Safari で開く」で Safari が開く／「閉じる」で元のページに残り、翻訳が続く／「このタブをホームに戻す」。
- [ ] 記事内の `tel:` / `mailto:` をタップ（あれば）→ 確認カードが出て、「開く」を押したときだけ別アプリが開く。ユーザー操作なしでカードが出ない。
- [ ] ログイン画面（例: Yahoo の Y! ログイン）では翻訳されない。

## 8. 操作性・見た目
- [ ] 片手で届く（アドレス欄はツールバーの真上＝下部）。アドレス欄をタップするとツールバーが引っ込み、アドレス欄がキーボードの真上に出る（キーボードに隠れない）。入力後・ページ側の入力欄のキーボード表示中は、バーがキーボードの上に乗らない。ボタンのラベルが読める。赤・橙の通知が読める（長い文は「詳しく見る」）。
- [ ] ダークモード・文字サイズ拡大（設定 > アクセシビリティ。**AX5**）・横向きで崩れない（AX サイズではツールバーはアイコンのみ）。
- [ ] VoiceOver: ホーム、タブ一覧、英語部分（ボタンとして読まれ、有効化で原文）、状態行、ペアリング確認。
- [ ] 他のアプリへ切り替えて戻る／ロック画面から戻る → 翻訳が続く。失敗表示が残っていれば自動で再試行され、ホームの接続カードも更新される。

## 9. 負荷・安全
- [ ] 長い記事を最後までスクロール → 発熱・バッテリー・Mac の負荷が許容範囲（先読みで Mac が常に忙しくないか）。
- [ ] Mac で Web 版を同時に使っても、アプリは「Mac が他の翻訳を処理中」と出して自動で続く。
- [ ] 家以外の Wi-Fi（カフェなど）へ**直接**つないでは使わない（外出先は §16 の Tailscale を使う）。使ってしまったらトークンと証明書を作り直す（`.mazemaze_token` と `.mazemaze_tls/` を削除 → `run_lan.sh` → QR を読み取り直す）。
- [ ] Mac の再起動・スリープ復帰・IP 変更後の復帰。VPN・ゲスト Wi-Fi では接続できないこと。Mac のファイアウォールの許可ダイアログ。

## 10. 既知の保留事項
- X は第2段階で、X に限り Safari 互換の UA と 2 つの目印を送ってアプリ内で開く（§11 参照）。Safari 拡張は作らない。
- 見出しがリンクの一覧ページはほとんど変わらない。
- 手入力のアドレスは暗号化なし（HTTP）のみ。暗号化は QR / 貼り付けのペアリングで使う。

## 12. 辞書・バーの自動格納（実機未確認）
- [ ] ページを下にスクロール → 下のアドレス欄とツールバーが隠れて表示が広くなる（上は空いている）。上に少しスクロール → 戻る。ページの先頭では常に出ている。ちらつき・内容のジャンプがない。固定ヘッダーのあるサイト（X など）で、ヘッダーがバーの下に隠れない。
- [ ] 画面下の小さな表示（ホスト名）を押すとバーが戻る。アドレス欄をタップするとバーが戻る。エラー・通知が出るとバーが戻る。設定「スクロールでバーを隠す」をオフにすると隠れない。VoiceOver ではバーが隠れない。横向き・文字サイズ拡大でも崩れない。
- [ ] 英語をタップ → 吹き出しの「辞書に保存」→「保存しました」。もう一度 →「保存済みです」。X のカード（投稿全体がリンクのもの）の上で押しても、投稿が開かない。
- [ ] ツールバーの「辞書」: 一覧に出る、検索できる、項目を開いてメモを書ける、「元のページを開く」で新しいタブが開く、スワイプ/ボタンで削除できる、書き出し（CSV・テキスト）の共有シートが出る。アプリを終了して起動し直しても残っている。
- [ ] ツールバーに「原文に戻す」が無い。翻訳ボタンのオフ → 全ページが原文に戻る、オンで再開。翻訳ボタンに回転表示/件数の丸が出る。

## 15. 単語の保存と、裏での意味の取得（実機未確認）
- [ ] 標準辞書から単語を保存 → 辞書の一覧に「単語」の項目が出て、「意味を調べています…」が出る → 数秒〜数十秒後に意味（その文での意味）が自動で入る。項目に、英語の句（原文の英語）と日本語の原文も出ている。
- [ ] 翻訳（ページを読んでいる最中）は遅くならない（保存直後に読み続けても、翻訳が詰まらない）。読むのをやめると、そのあと意味が入る。
- [ ] Mac を止めて保存 → 「調べています…」のまま。Mac を起動すると自動で入る。トークンが違う状態では、調べない（設定で直すと再開）。失敗した項目は「もう一度、自動で調べる」で再試行できる。
- [ ] 設定「保存した単語の意味を、裏で自動で調べる」をオフ → 保存しても調べない（日本語の原文が意味の代わりに出る）。CSV の書き出しに context_en / context_ja が入る。

## 13. 単語・句の意味（実機未確認）

- [ ] 「この文での意味（AI）」に切り替えたときだけ Mac に聞く（切り替えなければ通信しない）。標準辞書の画面から「単語を辞書に保存（原文つき）」→ 辞書に「単語」の項目として、原文つきで入る。

## 11. 第2段階（X をアプリ内で開く／貼り付けて翻訳）— すべて実機未確認
- [ ] 設定 > 翻訳するサイト の「X を Safari として開く」がオン（初期値）。`x.com/（ユーザー名）` を開いて **Safari へ誘導されず X が表示される**（ログアウト状態では、画面の前面に X 自身の「アプリで開く」「ログイン」の案内が出る。これは X の通常の表示）。誘導された場合は案内カードが出る（記録してください）。
- [ ] X にログイン（自分のアカウント）できるか。メール/パスワードのログインが通るか、Google / Apple のログインが弾かれるか（弾かれても回避しない）。ログイン後のタイムラインで、投稿の日本語が英語混じりになるか。名前・時刻・リンク・ボタンが変わらないか。英語部分をタップすると元の日本語が出る（カードが開いてしまわない）。DM・設定・ログイン画面は翻訳されない。

- [ ] X 以外（Yahoo!ニュース）で UA が変わっていない（記事が従来どおり開く）。X の記事内リンク（外部サイト）を開いても問題ない。

## 16. 外出先（Tailscale）— 実機未確認
