# iPhone 実機チェックリスト（iPhone 単体版）

シミュレータと自動テストで確認できない、実機でだけ分かることの一覧です。**すべて未確認**（Mac 版の時代に確認した項目は、ブランチ `mac-local-model` の同名ファイルにあります）。結果は、気づいたことだけでも記録してください。

## 0. 入れ方
- [ ] Xcode で Team を選んで ▶（無料の Apple ID は 7 日で失効。失効後に**上書きで入れ直すと設定は残る**。**アプリを削除すると設定・お気に入りは消える**）。iPhone の「VPN とデバイス管理」で信頼。
- [ ] Xcode のスキームの「Arguments」に `-Mazemaze…` が残っていない。可能なら Run の Build Configuration を **Release** にして確認。
- [ ] 初回起動で、ホームが出る。ネットワーク（ローカルネットワークなど）の許可ダイアログが**出ない**。

## 1. Apple 翻訳（既定）
- [ ] 設定 > 翻訳と意味の作り方: 「ページの翻訳」が Apple 翻訳。状態に「翻訳データが未ダウンロード」と出る（未取得のとき）。
- [ ] 「翻訳データをダウンロード」を押す → システムの確認画面が**設定画面の上に**出る → 終わると「使えます」になる。キャンセルしたら「未ダウンロード」のまま。
- [ ] Yahoo!ニュースの記事で英語混じりになる。最初の英語が出るまでの時間を記録。長い記事で、スクロールに合わせて続けて訳される。**ページを開いたあとに機内モードにしても**、続きの翻訳が動く（通信が要るのはページの読み込みだけ）。
- [ ] 英語部分をタップで元の日本語。翻訳オフで元に戻る。リンク・ボタン・入力欄は変わらない。リンクをタップして遷移できる。
- [ ] 訳の質（Apple 翻訳）を記録。迷う句は、日本語と英語を見比べる。
- [ ] 「貼り付けて翻訳」の画面でも Apple 翻訳が動く（見えない部品が、貼り付け画面・設定画面の裏でも動くか）。

## 2. Apple Intelligence
- [ ] 設定で「ページの翻訳」を Apple Intelligence にする → 対応機種で、設定アプリで Apple Intelligence がオン、日本語の言語設定なら「使えます」。使えないときは、理由と次の行動が日本語で出る。
- [ ] 同じ記事で翻訳。**周辺の文を訳に混ぜていないか**（句の訳が、その句だけの内容か）。長い記事でも落ちない・極端に熱くならない。Apple 翻訳と見比べる。
- [ ] 単語をタップ →「意味を調べる」→ 標準辞書のあと「この文での意味（AI）」に切り替えると、数秒で意味が出る。見出し語・品詞が正しい（例: took → take）。意味が日本語で出る。「例文・よく使う形」も出る。
- [ ] 単語を保存 → 裏で意味が入る（一覧の「調べています…」が消える）。翻訳（読んでいる最中）が詰まらない。
- [ ] 設定の「翻訳の方法」を切り替えると、開いているページが新しい方法でやり直される。入力中の文章は消えない。
- [ ] Apple Intelligence がオフ／非対応のとき: 翻訳・意味とも、原文は消えず、設定を開くボタン付きのメッセージが出る。標準辞書は使える。

## 3. ホーム・お気に入り・履歴・検索
- [ ] 起動直後は Mazemaze のホーム（Yahoo!ニュースなどが勝手に開かない）。状態の欄（「ページの翻訳は iPhone の中で行います」/ 準備が必要なとき）、お気に入り、おすすめ、最近のサイト、検索の説明が読める。
- [ ] 「おすすめ」の「追加」→ お気に入りに入る。メニュー（⋯）「お気に入りに追加」→ 入る（ログイン系は断られる）。長押しで削除。
- [ ] 記事を開いてホームに戻ると「最近開いたサイト」に載る。「履歴を消去」→ 確認が出て消える。
- [ ] アドレス欄に**語句**を入れて Go → 確認なしで、Google の検索結果が開く。設定の「検索」で Yahoo! JAPAN・Bing・DuckDuckGo に変えると、そちらで開く。URL（`x.com`）はそのまま開く。
- [ ] `javascript:alert(1)` などは「開けません」と出る。

- [ ] ページの画像を長押し →「"写真"に追加」: 初回に許可を聞かれ、許可すると保存できる。**落ちない**（以前は、写真への追加の説明が Info.plist に無く、強制終了していた）。許可しない場合も落ちない。

## 4. タブ・バー・操作性
- [ ] 新しいタブ・切り替え（開いたままのタブは再読み込みされない）。8 個まで。5 個目以降は古いタブが休止中になり、選ぶと読み込み直す。タブ一覧のカードに状態が出る。
- [ ] アプリを終了して起動し直す → 前回のタブが戻る（公開ページのみ）。設定でオフにすると戻らない。履歴を消去したあとに再起動しても、消した内容が戻らない。
- [ ] ページを下にスクロールするとアドレス欄とツールバーが隠れ、上で戻る。固定ヘッダーのあるサイト（X など）で、ヘッダーがバーの下に隠れない。アドレス欄をタップするとキーボードの真上に出る。
- [ ] ダークモード・文字サイズ最大（AX5）・横向きで崩れない。VoiceOver で、ホーム・タブ一覧・英語部分・設定が使える。
- [ ] 他のアプリへ切り替えて戻る／ロック画面から戻る → 翻訳が続く。失敗表示が残っていれば自動で再試行される。

## 5. サイトの制限・X
- [ ] 記事内の `tel:` / `mailto:` をタップ → 確認カードが出て、「開く」を押したときだけ別アプリが開く。
- [ ] ログイン画面（例: Yahoo の Y! ログイン）では翻訳されない。
- [ ] 設定「X を Safari として開く」がオン（初期値）。`x.com/（ユーザー名）` を開いて、Safari へ誘導されず X が表示される。ログイン後のタイムラインで、投稿の日本語が英語混じりになる。名前・時刻・リンク・ボタンが変わらない。ヘッダー（検索欄）がステータスバーの下に出る。
- [ ] オフにすると、新しいタブで X を開いたとき案内カードが出る。X 以外で UA が変わっていない。

## 6. 辞書・意味・発音
- [ ] 英語をタップ → 吹き出しの「辞書に保存」→「保存しました」。もう一度 →「保存済みです」。X のカード（投稿全体がリンク）の上で押しても、投稿が開かない。
- [ ] 辞書: 一覧・検索・メモ・「元のページを開く」・削除・書き出し（CSV・テキスト）。アプリを終了して起動し直しても残る。
- [ ] 単語をタップ →「意味を調べる」→ シートの中に標準辞書の内容が出る（クラッシュしない）。単語の並びで切り替わる。何度か繰り返しても落ちない。落ちたら次の起動で「標準辞書で〜を開く」のボタン方式になる（落ちた時刻を記録）。
- [ ] 設定 > 一般 > 辞書 で Oxford 系を解除 → シートにはウィズダムだけが出る。
- [ ] 🔊 で英語が読み上げられる（サイレントモードでも鳴る）。鳴らないときは理由が出る。拡張／プレミアムの声をダウンロードすると自然になる。
- [ ] 辞書の項目から「意味を調べ直す」→ 単語チップを押しても項目が別のカードに変わらない。保存後に「例文…」を押すと保存済みの項目にも反映される。
- [ ] 貼り付け画面の英語でも、同じように意味を調べられる。

## 7. 貼り付けて翻訳
- [ ] ホームの「貼り付けて翻訳」: 日本語をコピー → 貼り付け → 翻訳する。英語混じりになり、タップで原文、「原文に戻す」で元に戻る、「コピー」で表示中の文章がコピーされる。閉じるとタブ一覧にも履歴にも残らない。アプリスイッチャーで本文が見えない。
- [ ] ショートカットアプリで「URL を開く: mazemaze://paste」→ 貼り付け画面が開く（設定やタブ一覧が開いていても開く）。

## 8. データ・バックアップ・署名
- [ ] 設定 > データ > バックアップと復元: 件数が合っている。「バックアップを書き出す」→ ファイルアプリ（iCloud Drive を含む）に保存でき、「最後に書き出した日」が更新される。
- [ ] 辞書に表現を保存 → アプリを削除せずに、いったん辞書から削除 →「バックアップを取り込む」で戻る（確認画面の件数、結果の件数が合う。もう一度取り込んでも増えない）。
- [ ] 違う種類の JSON や、壊れたファイルを選ぶと、日本語のメッセージで断られる。
- [ ] 翌日の最初の起動後、「前の状態に戻す」に控えが出る。選ぶと戻り、戻す前の辞書も控えに残る。
- [ ] 設定 > このアプリについて: 署名の期限が出る（読み取れなければ「確認できません」）。残り 2 日以内で、ホームに黄色い案内が出る。
- [ ] 期限が切れたあと、**削除せずに** Xcode から ▶ で入れ直して、辞書・お気に入り・設定が残っている（実際の期限切れからの復旧）。
- [ ] お気に入りが 40 件近くあるときに取り込んでも、いまのお気に入りが消えない（空きの分だけ増える）。
- [ ] 設定 > バックアップと復元 > 読み込めなかった辞書のファイル（ある場合）: 共有で取り出せる。削除は確認が出る。
- [ ] 設定 > エンジンの確認: 30 文で実行でき、「原文の保持: すべて一致」。やめる、が効く。

## 9. 負荷
- [ ] 長い記事を最後までスクロール → 発熱・バッテリーが許容範囲（Apple Intelligence のとき特に）。
- [ ] 機内モードで、「貼り付けて翻訳」・標準辞書・意味（AI）・読み上げがすべて動く（記事そのものは、読み込めた分だけ）。
